# Multi-Sensor Track Fusion (Still work in progress)

A Python simulation project for multi-target tracking and radar sensor fusion.

The project currently includes:

- randomized multi-target scenarios
- range-bearing radar simulation
- Doppler radar simulation
- measurement noise, clutter, and missed detections
- Extended Kalman Filter state estimation
- statistical gating
- GNN / Hungarian data association
- track initiation and track management
- asynchronous multi-sensor fusion
- visualization scripts
- Monte Carlo evaluation
